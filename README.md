## 🚀 Projects That Do More Than Just Run

### 📉 Customer Churn Prediction — *"Who's about to leave, and why?"*
A telecom company's worst nightmare is losing customers silently. This model catches them before they walk.

- 🎯 **93.4% accuracy, 97% recall** on churners — built on a **Random Forest** trained on 7K+ real telecom records
- ⚖️ Tackled brutal class imbalance with **SMOTEENN**, so the model doesn't just predict the easy majority class
- 🔧 A **50+ feature pipeline** with strict train-serve schema alignment — the boring-but-critical part that makes predictions actually trustworthy in production
- 🖥️ Shipped as a **live Streamlit app** for real-time churn risk scoring — including untangling nasty cross-platform serialization bugs

**Stack:** `Python` `Scikit-learn` `Pandas` `SMOTEENN` `Streamlit` &nbsp; [🔗 Live Demo](#)

---

### 📈 Stock Volatility Forecasting — *"How wild will tomorrow be?"*
Volatility, not price, is the number traders actually lose sleep over. This system forecasts it.

- 📊 Predicts **next-day volatility for 5 NSE stocks** using **LightGBM + GARCH**, with 20+ engineered features and walk-forward validation
- 🏁 **Beat the classic GARCH baseline** on both MAE and RMSE — old-school statistics vs. gradient boosting, and boosting won
- ⚡ Backed by a **FastAPI REST API** + live **Streamlit dashboard**, pulling real-time prices straight from Yahoo Finance

**Stack:** `Python` `LightGBM` `GARCH` `FastAPI` `Streamlit` &nbsp; [🔗 Live Demo](#)
